# OrderFlow API

**OrderFlow** — REST API для управления заказами интернет-магазина, разработанный на Java и Spring Boot.

Проект демонстрирует работу с транзакциями, конкурентными запросами, JWT-аутентификацией, ролевой авторизацией, PostgreSQL, Redis и автоматизированным тестированием.

## Технологии

- Java 17
- Spring Boot 4
- Spring Security + JWT
- Spring Data JPA / Hibernate
- PostgreSQL 17
- Redis
- Liquibase
- Maven
- JUnit 5, Mockito, MockMvc
- Testcontainers
- Docker / Docker Compose
- GitHub Actions

## Функциональность

**Пользователь:**
- Регистрация и авторизация
- Просмотр товаров
- Создание заказов из нескольких товаров
- Просмотр собственных заказов
- Отмена заказа с учётом его состояния
- Оплата заказа и обработка результата оплаты

**Администратор:**
- Управление товарами и категориями
- Изменение цен
- Управление остатками товаров
- Просмотр всех заказов

## Бизнес-логика

### Резервирование товаров

При создании заказа система проверяет наличие товаров и резервирует необходимое количество.

- Доступный остаток уменьшается
- Зарезервированный остаток увеличивается
- При успешной оплате резерв списывается
- При неуспешной оплате товар возвращается в доступный остаток

Для предотвращения продажи одного и того же последнего товара нескольким покупателям используются транзакции и блокировки на уровне базы данных.

### Безопасность

- Аутентификация через JWT
- Разграничение прав USER и ADMIN
- Проверка принадлежности заказов пользователю
- Ограничение административных операций

### Redis

Redis используется для кэширования данных каталога товаров.

Кэш обновляется при изменении цены или удалении товара. Остатки товаров не кэшируются, чтобы избежать отображения устаревшего количества.

## Запуск через Docker Compose

**Требования:** Docker Desktop с поддержкой Docker Compose.

1. Клонировать репозиторий:

```bash
git clone https://github.com/rikkimars123-netizen/OrderFlow.git
cd OrderFlow
```

2. Создать файл `.env` в корне проекта на основе `.env.example` и указать собственный `JWT_SECRET`.

3. Собрать приложение:

```bash
./mvnw clean package
```

На Windows:

```powershell
.\mvnw.cmd clean package
```

4. Запустить контейнеры:

```bash
docker compose up --build -d
```

Приложение доступно по адресу:

`http://localhost:8080`

Docker Compose запускает PostgreSQL, Redis и Spring Boot приложение.

## Основные API endpoints

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/auth/register` | Регистрация |
| POST | `/auth/login` | Авторизация |
| GET | `/products` | Список товаров |
| GET | `/products/{id}` | Информация о товаре |
| GET | `/products/{id}/catalog` | Кэшируемые данные каталога |
| POST | `/products` | Создание товара (ADMIN) |
| PUT | `/products/{id}` | Изменение цены (ADMIN) |
| DELETE | `/products/{id}` | Удаление товара (ADMIN) |
| POST | `/orders` | Создание заказа |
| GET | `/orders` | Собственные заказы |
| GET | `/orders/{orderId}` | Получение заказа |
| PATCH | `/orders/{orderId}/cancel` | Отмена заказа |
| GET | `/orders/all` | Все заказы (ADMIN) |
| POST | `/payments/{orderId}` | Создание платежа |
| PATCH | `/payments/{orderId}/success` | Успешная оплата |
| PATCH | `/payments/{orderId}/failed` | Неуспешная оплата |
| GET | `/inventory/{productId}` | Просмотр остатков |

## Тестирование

В проекте реализованы:

- Unit-тесты сервисного слоя с Mockito
- MVC-тесты контроллеров с MockMvc
- Тесты авторизации и разграничения доступа
- Интеграционные тесты с PostgreSQL через Testcontainers

Запуск тестов:

```bash
./mvnw test
```

## CI

При отправке изменений в репозиторий автоматически выполняются сборка и тестирование проекта.
